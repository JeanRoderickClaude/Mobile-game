# Mobile-game

Top-down browser game prototype: walk a protest route to the finish without being caught by police. Portrait, works on desktop (arrow keys or WASD) and phone browsers (touch joystick).

Play it at https://jeanroderickclaude.github.io/Mobile-game/.

```
npm install
npm run dev      # open the "Network" address + /Mobile-game/ on a phone
npm run build    # production build into dist/
```

Project notes for development sessions are in `CLAUDE.md`.
